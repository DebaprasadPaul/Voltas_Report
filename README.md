## 🚀 Model Architecture & Methodology
Unlike standard projections, this model is built on an **Analytical Intelligence** framework:
- **Bottom-Up Revenue Drivers**: Volume-mix analysis across Tier 1, 2, and 3 cities.
- **Margin Reversion Thesis**: Analyzing the impact of PLI schemes and capacity scaling.
- **Structural Integrity**: Hard-coded error validation and matrix-based checksums.
- **Sensitivity Analysis**: Multi-variable DCF testing across WACC and Terminal Growth corridors.

## 🛠️ Infrastructure
- **Styling**: Vanilla CSS with modern Glassmorphism.
- **Interactivity**: Chart.js for dynamic visualization.
- **Framework**: Responsive HTML5/Tailwind for executive-level presentation.
